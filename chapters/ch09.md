# 第9章：序列的挑战——RNN、LSTM与注意力机制的萌芽（2014–2017）

CNN在图像领域大杀四方，但有一个领域它很难直接处理：**序列数据**。文本是词的序列，语音是帧的序列，时间序列是数值的序列。这些数据有一个共同特征：长度不固定，而且顺序很重要——"狗咬人"和"人咬狗"词完全一样但意思完全不同。

处理变长序列、记住之前的信息、理解上下文——这是循环神经网络（RNN）被设计来解决的问题。但RNN自己也遇到了一个严重的问题：它记不住太长的东西。

---

## RNN：处理序列的天然选择

### 为什么CNN不适合序列

CNN的核心假设是**局部性和平移不变性**——一个卷积核在所有位置做同样的操作。这对图像很合适（一只猫在图像左边和右边都应该被识别为猫），但对序列不合适：

- 序列的"位置"有语义意义——第一个词和最后一个词的角色完全不同
- 序列的"感受野"需要覆盖整个历史——理解"他"指代谁，可能需要回溯很多句
- 变长输入需要变长计算——CNN的固定大小卷积核无法自然处理

### RNN的设计

RNN（Recurrent Neural Network）的核心思想：**用同一个网络处理序列中的每个元素，同时维护一个隐藏状态来"记住"之前的信息**。

```
对于序列 x₁, x₂, ..., xₜ:
hₜ = f(W_hh · hₜ₋₁ + W_xh · xₜ + b)    # 隐藏状态更新
yₜ = W_hy · hₜ + b                         # 输出
```

f通常是tanh或ReLU。关键是**权重在所有时间步共享**——同一个W_hh、W_xh用于处理每个输入。这让RNN可以处理任意长度的序列。

隐藏状态hₜ是RNN的"记忆"——它编码了从x₁到xₜ的所有历史信息（理论上）。每一步，RNN把新输入xₜ和旧记忆hₜ₋₁结合起来，产生新的记忆hₜ。

### RNN的直觉

想象你在读一本书，每读一个词就更新你对故事的理解。你的"理解状态"就是hₜ——它融合了之前所有词的信息。当你读到"他走进了房间"，你的理解状态包含了"他"是谁、这个房间是什么、之前发生了什么。

这个直觉是RNN吸引人的原因——它模拟了人类处理序列信息的方式。但实际中，RNN有一个致命的问题。

---

## 梯度消失再次出现——但这次是时序维度上的

第4章讲了深度网络在层数维度上的梯度消失。RNN在时间维度上有同样的问题。

把RNN按时间步展开：

```
x₁ → [RNN] → h₁ → [RNN] → h₂ → [RNN] → h₃ → ... → hₜ → y
```

这就像一个t层的深度网络——只不过每一层共享相同的权重。反向传播通过时间（BPTT，Backpropagation Through Time）计算梯度时，需要沿时间步反向传递：

```
∂L/∂h₁ = ∂L/∂hₜ · Πₖ₌₂ᵗ (∂hₖ/∂hₖ₋₁)
       = ∂L/∂hₜ · Πₖ₌₂ᵗ W_hh · diag(f'(·))
```

如果W_hh的最大特征值小于1（这通常是训练后的正常状态），这个连乘会指数衰减：

```
20步后：λ²⁰ → 几乎为零
100步后：λ¹⁰⁰ → 完全为零
```

RNN"忘记"了序列开头的信息。不是因为它选择忘记，而是因为梯度无法回传那么远——它无法学到长距离的依赖关系。

这个问题不是实现上的bug，而是RNN架构的内在限制。就像sigmoid激活函数导致深度网络的梯度消失一样，RNN的递归结构导致时间维度上的梯度消失。

---

## LSTM：门控机制解决长程依赖（1997提出，2010s重新流行）

1997年，Sepp Hochreiter和Jürgen Schmidhuber提出了LSTM（Long Short-Term Memory）——通过门控机制让RNN学会"什么时候忘、什么时候记"。

### 为什么LSTM不是1997年就爆发

LSTM在1997年就提出了，但直到2012-2013年才被大规模应用。原因跟CNN一样：没有足够的数据和算力。LSTM比普通RNN参数多4倍，训练更慢，在小数据上优势不明显。只有当数据规模和算力都上来之后，LSTM的优势才显现。

### LSTM的核心：细胞状态和三个门

LSTM在普通RNN的基础上增加了一条"细胞状态"（cell state）的直通路径和三个门：

```
细胞状态 Cₜ：信息的主干道，可以直接从t=0流到t=T，几乎没有衰减
遗忘门 fₜ：决定Cₜ₋₁中哪些信息要丢弃
输入门 iₜ：决定新信息中哪些要写入Cₜ
输出门 oₜ：决定Cₜ中哪些信息要输出为hₜ
```

具体计算：

```
fₜ = σ(Wf · [hₜ₋₁, xₜ] + bf)    # 遗忘门：0=遗忘，1=保留
iₜ = σ(Wi · [hₜ₋₁, xₜ] + bi)    # 输入门：0=不写入，1=写入
C̃ₜ = tanh(Wc · [hₜ₋₁, xₜ] + bc) # 候选新信息
Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ       # 细胞状态更新：旧记忆×遗忘门 + 新信息×输入门
oₜ = σ(Wo · [hₜ₋₁, xₜ] + bo)    # 输出门
hₜ = oₜ ⊙ tanh(Cₜ)                # 隐藏状态：输出门×处理后的细胞状态
```

### 为什么LSTM能解决梯度消失

关键在细胞状态的更新公式：Cₜ = fₜ ⊙ Cₜ₋₁ + iₜ ⊙ C̃ₜ

当遗忘门fₜ接近1时，Cₜ ≈ Cₜ₋₁——信息原封不动地从上一步传到下一步。梯度在反向传播中也沿着这条路径直通：

```
∂Cₜ/∂Cₜ₋₁ = fₜ + Cₜ₋₁ · ∂fₜ/∂Cₜ₋₁
```

当fₜ=1时，∂Cₜ/∂Cₜ₋₁ = 1。**梯度不会消失**。

这不是魔法——LSTM只是给了网络一条"可以选择不衰减"的路径。普通RNN中，梯度衰减是强制的（乘以W_hh，特征值<1就衰减）。LSTM中，遗忘门可以选择"不衰减"（fₜ=1），让信息 indefinitely 地传递下去。

### LSTM的成功应用

LSTM在2013-2017年间成为序列建模的主力：

- **语音识别**：Google在2015年用LSTM替代了HMM+GMM，语音识别错误率大幅下降
- **机器翻译**：Google Translate在2016年从基于短语的统计翻译切换到LSTM-based神经机器翻译，翻译质量飞跃
- **文本生成**：字符级LSTM可以生成风格化文本
- **时间序列预测**：金融、天气、交通流量预测

## GRU：LSTM的简化版

2014年，Kyunghyun Cho等人提出了GRU（Gated Recurrent Unit）——LSTM的简化版本。

GRU把遗忘门和输入门合并成一个"更新门"zₜ，把细胞状态和隐藏状态合并：

```
rₜ = σ(Wr · [hₜ₋₁, xₜ])        # 重置门
zₜ = σ(Wz · [hₜ₋₁, xₜ])        # 更新门
h̃ₜ = tanh(W · [rₜ⊙hₜ₋₁, xₜ])  # 候选隐藏状态
hₜ = zₜ⊙hₜ₋₁ + (1-zₜ)⊙h̃ₜ      # 隐藏状态更新
```

GRU比LSTM少一个门和一条状态路径，参数更少，训练更快。在很多任务上，GRU的表现跟LSTM相当。

实践中，LSTM和GRU的选择往往取决于具体任务和经验——没有哪个绝对更好。

## Seq2Seq：编码器-解码器架构（2014）

2014年，Ilya Sutskever等人发表了《Sequence to Sequence Learning with Neural Networks》，提出了一个优雅的框架：**用一个LSTM把源序列编码成一个固定长度的向量，再用另一个LSTM把这个向量解码成目标序列**。

```
源序列: "I love you" → [编码器LSTM] → 向量v → [解码器LSTM] → "我爱你"
```

### 为什么这是突破

在Seq2Seq之前，机器翻译用统计方法（基于短语的模型），需要大量的手工特征和语言特定的工程。Seq2Seq是第一个端到端的神经机器翻译模型——你只需要平行语料（源语言-目标语言句子对），不需要任何语言学知识。

### 瓶颈：固定长度向量

Seq2Seq的致命问题：**整个源序列被压缩成一个固定长度的向量v**。不管源句子多长——5个词还是50个词——都是同一个维度的向量。

这就像把一整本书总结成一段话——短书还行，长书必然丢失大量信息。实验表明，当源句子超过20个词时，Seq2Seq的翻译质量急剧下降。

这个瓶颈催生了AI领域近十年来最重要的架构创新之一：注意力机制。

---

## 注意力机制的诞生：Bahdanau注意力（2014）

2014年，Dzmitry Bahdanau等人在论文《Neural Machine Translation by Jointly Learning to Align and Translate》中提出了一个简单但革命性的想法：**解码时不要只用最后一个编码器状态，而是动态关注源序列的不同部分**。

### 原理

编码器仍然把源序列编码成一系列隐藏状态 h₁, h₂, ..., hₜ（而不是只用最后一个hₜ）。

解码时，对于目标序列的每个位置j，计算一个注意力分布：

```
eᵢⱼ = a(sⱼ₋₁, hᵢ)           # 注意力得分：解码器状态sⱼ₋₁和编码器状态hᵢ的相关性
αᵢⱼ = softmax(eᵢⱼ)            # 注意力权重：归一化
cⱼ = Σ αᵢⱼ · hᵢ               # 上下文向量：编码器状态的加权平均
```

然后解码器用上下文向量cⱼ（而不是固定的v）来生成当前输出。

### 直觉

翻译"I love you"为"我爱你"时：

- 生成"我"时，注意力集中在"I"上
- 生成"爱"时，注意力集中在"love"上
- 生成"你"时，注意力集中在"you"上

注意力机制让解码器在每个时间步"回头看"源序列，动态决定最关注哪个部分。这解决了Seq2Seq的瓶颈——不再需要把整个源序列塞进一个固定向量。

### 后果：这是Transformer的前奏

Bahdanau注意力当时还附着在RNN/LSTM上——编码器是双向LSTM，解码器是单向LSTM，注意力是附加组件。但它建立了一个关键的思想：**让模型动态选择关注什么，而不是被迫把所有信息压缩到固定维度**。

三年后，这个思想被推到极致：**去掉RNN，只保留注意力**——这就是Transformer。

---

## 本章技术要点

1. **RNN**：用隐藏状态编码历史信息，权重在时间步共享。天然适合变长序列，但存在时序维度上的梯度消失——记不住长距离依赖。

2. **LSTM**：细胞状态+三个门（遗忘门、输入门、输出门）。关键创新是给梯度一条"可以选择不衰减"的路径（fₜ=1时∂Cₜ/∂Cₜ₋₁=1）。2013-2017年序列建模的主力。

3. **GRU**：LSTM的简化版，合并门和状态，参数更少，性能相当。

4. **Seq2Seq**：编码器-解码器架构，端到端机器翻译的突破。瓶颈是把源序列压缩成固定长度向量，长序列信息丢失严重。

5. **注意力机制**：解码时动态关注源序列不同部分，解决了Seq2Seq的固定向量瓶颈。这是Transformer的前奏——当注意力从"附加组件"变成"唯一组件"时，Transformer就诞生了。
