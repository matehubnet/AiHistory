# 第8章：CNN的进化——视觉理解的深化（2013–2015）

AlexNet证明了深度学习在图像识别上可行。但AlexNet只是一个开始——它留下了大量未解的问题：网络应该多深？多宽？怎么防止过拟合？怎么在保持精度的同时加速推理？

2013到2015的三年间，CNN的架构经历了爆发式的进化。每年ImageNet竞赛都带来新的突破，每个突破都回答了一个关键问题。

---

## VGGNet：更深的网络一定更好吗？（2014）

牛津大学Visual Geometry Group的Karen Simonyan和Andrew Zisserman提出了一个简洁的实验：**用更小的卷积核、更深的网络，效果会更好吗？**

### 设计原则

VGGNet的核心设计原则是**用3×3的小卷积核替代大卷积核**：

- AlexNet用了11×11、5×5、3×3的卷积核
- VGGNet全部用3×3的卷积核

为什么3×3就够了？两个3×3的卷积层叠加，感受野等于一个5×5的卷积——但参数更少（2×3×3=18 vs 5×5=25），而且中间多了一次非线性变换（两次ReLU vs 一次ReLU），表达能力更强。

```
一个5×5卷积: 25参数, 1次非线性
两个3×3卷积: 18参数, 2次非线性  ← 参数更少，非线性更强
```

VGGNet-16的架构：13个卷积层+3个全连接层，共1.38亿参数。

### 结果与教训

VGGNet在ILSVRC 2014上取得了7.3%的top-5错误率（AlexNet是16.4%），证明了**更深的网络确实更好**。

但VGGNet也暴露了一个问题：**参数太多了**。1.38亿参数中，绝大部分在最后三个全连接层。模型文件超过500MB，推理速度慢，部署困难。

VGGNet的真正贡献不是架构本身（它太笨重了），而是它用实验验证了一个直觉：**深度是提升性能的关键维度**。这为后来ResNet的突破做了铺垫。

---

## GoogLeNet/Inception：宽度也很重要（2014）

Google的Christian Szegedy团队从另一个方向思考：与其只往深处走，不如让每一层**更宽**——用不同大小的卷积核并行提取多尺度特征。

### Inception模块

Inception模块的核心思想：**让网络自己选择用什么特征**。

```
          ┌── 1×1 卷积 ──────────────────┐
输入 ─────┼── 3×3 卷积 ──────────────────┼── 拼接 ──→ 输出
          ├── 5×5 卷积 ──────────────────┤
          └── 3×3 最大池化 → 1×1 卷积 ──┘
```

四个分支并行计算，然后在通道维度上拼接。1×1卷积捕获逐像素特征，3×3捕获局部模式，5×5捕获更大范围的模式，池化捕获最粗粒度的特征。

但这里有一个问题：四个分支的输出拼接起来通道数太多，计算量爆炸。解决方案是**在3×3和5×5卷积之前加1×1卷积做降维**（bottleneck）：

```
          ┌── 1×1 卷积 ──────────────────────────┐
输入 ─────┼── 1×1降维 → 3×3 卷积 ────────────────┼── 拼接
          ├── 1×1降维 → 5×5 卷积 ────────────────┤
          └── 3×3 最大池化 → 1×1 降维 ───────────┘
```

1×1卷积做降维是Inception最精妙的设计。它把N个输入通道压缩到M个（M<<N），然后在低维空间中做3×3或5×5卷积，计算量大幅降低。

### 结果

GoogLeNet有22层，但只有500万参数——比VGGNet少28倍。ILSVRC 2014 top-5错误率6.7%，比VGGNet略好，但参数少得多，推理速度快得多。

GoogLeNet的教训：**网络设计不只是"更深"，还要"更高效"**。用更少的参数做更多的事，这是工业部署的前提。

## ResNet：残差连接——深层网络训练的突破（2015）

2015年，微软亚洲研究院的何恺明团队做了一个实验：把VGGNet从16层加深到56层，结果**更深的网络反而性能更差**。

这不是过拟合——训练误差也更高。一个56层的网络连训练集都学不好，而16层的网络可以。这被称为**退化问题**（Degradation Problem）。

这很反直觉。按理说，56层网络可以退化为16层网络——只要中间40层什么都不做（恒等映射），56层网络至少应该跟16层一样好。但反向传播找不到这个恒等映射——它找不到一组权重让中间层精确地"什么都不做"。

何恺明的洞察：**让网络学习残差（residual），而不是学习完整的映射**。

### 残差学习的原理

假设我们想让网络学习一个映射H(x)。传统网络直接学习H(x)。

ResNet让网络学习**残差** F(x) = H(x) - x，然后通过跳跃连接（skip connection）得到H(x) = F(x) + x。

```
传统网络:     x → [权重层] → H(x)
ResNet:       x → [权重层] → F(x) → F(x)+x
              ↑___________________↑  (跳跃连接)
```

### 为什么这能解决退化问题

如果最优映射是恒等映射（H(x)=x），那么残差F(x)应该为零。让网络学习"输出零"比学习"输出等于输入"容易得多——权重只需要趋向零即可，不需要精确地配置成恒等矩阵。

更关键的是梯度流动。在反向传播中，跳跃连接让梯度有一条"直通"路径：

```
∂L/∂x = ∂L/∂H(x) · (∂F(x)/∂x + 1)
```

那个"+1"来自跳跃连接。不管∂F(x)/∂x多小（甚至为零），梯度至少有∂L/∂H(x)·1的分量直接传到输入。**梯度不会消失**。

### 结果

ResNet-152有152层，ILSVRC 2015 top-5错误率3.57%——**首次超越人类水平**（人类约5.1%）。

从22层（GoogLeNet）到152层（ResNet），一年之内网络深度翻了7倍。而且ResNet-152的训练误差低于ResNet-56——退化问题被彻底解决。

### 残差连接的深远影响

残差连接不只是解决了一个具体问题，它改变了深度网络的架构哲学：

1. **跳跃连接成为标配**。后来的DenseNet（每一层跟所有前面层连接）、U-Net（编码器-解码器之间的跳跃连接用于图像分割）、Transformer中的残差连接——都源自ResNet的思想。

2. **"让网络学习增量"而非"学习全部"**。这个思想在后续架构中反复出现：增量更新、差分学习、渐进优化。

3. **深层网络=多个浅层网络的隐式集成**。Veit等人在2016年的分析表明，ResNet可以被看作是不同长度的路径的集成——残差连接创造了多条从输入到输出的路径，网络的行为是这些路径的集成。这解释了ResNet为什么不容易过拟合。

## 目标检测：从R-CNN到YOLO

ImageNet竞赛解决的是图像分类问题："这张图里是什么？"但实际应用更常需要目标检测："这张图里有什么？在哪个位置？"

### R-CNN系列

R-CNN（Regions with CNN features，2014）的思路：

1. 用选择性搜索（Selective Search）在图像中生成约2000个候选区域
2. 每个候选区域缩放到固定大小，用CNN提取特征
3. 用SVM对每个区域的特征做分类

问题：2000个区域各自过一遍CNN，太慢了。一张图需要约47秒。

Fast R-CNN（2015）：整张图过一遍CNN得到特征图，然后在特征图上提取候选区域的特征。速度提升到约2秒。

Faster R-CNN（2015）：用区域建议网络（Region Proposal Network，RPN）替代选择性搜索，让候选区域的生成也由神经网络完成。端到端训练，速度约0.2秒/图。

### YOLO：一次看全图

YOLO（You Only Look Once，2016）的思路完全不同：**不做区域建议，直接在全图上预测所有目标的位置和类别**。

把图像分成S×S的网格，每个网格预测B个边界框和C个类别概率。一次前向传播输出所有预测。

YOLO的速度：45帧/秒——实时检测。精度略低于Faster R-CNN，但速度快了两个数量级。

速度与精度的权衡是目标检测的核心设计选择。Faster R-CNN追求精度（两阶段：先找区域再分类），YOLO追求速度（一阶段：同时预测位置和类别）。后来的SSD和YOLOv2/v3在两者之间找到了更好的平衡。

## CNN无处不在

2015年之后，CNN不再只是图像分类的工具，它渗透到了视觉理解的方方面面：

- **语义分割**（Semantic Segmentation）：对每个像素分类。FCN（2015）把全连接层替换为卷积层，实现端到端的像素级预测。
- **人脸识别**：FaceNet（2015）用CNN学习人脸的嵌入表示（128维向量），两个向量的距离反映两张脸的相似度。
- **风格迁移**（Neural Style Transfer，2015）：用CNN的不同层分别提取"内容"和"风格"，生成保留内容但具有新风格的图像。

CNN的统治地位一直持续到2020年，当Vision Transformer（ViT）出现时才开始被挑战。但即使到2026年，CNN在边缘设备和实时应用中仍然是首选——因为它的归纳偏置（局部性、平移不变性）让它在小数据和低算力场景下比Transformer更高效。

---

## 本章技术要点

1. **VGGNet**：验证了"更深=更好"，但暴露了参数爆炸问题。3×3小卷积核的设计原则被后续架构继承。

2. **Inception/GoogLeNet**：多尺度并行特征提取+1×1卷积降维。用更少参数做更多事，是高效网络设计的先驱。

3. **ResNet的残差连接**：让网络学习F(x)=H(x)-x而非H(x)，跳跃连接让梯度直通。这是深度学习史上最重要的架构创新之一——没有它，后续的Transformer、大模型都不可能训练到足够的深度。

4. **目标检测的演进**：R-CNN→Fast R-CNN→Faster R-CNN→YOLO，从"先找区域再分类"到"一次看全图"，速度与精度的权衡。

5. **CNN的归纳偏置**：局部性（卷积核只看局部区域）和平移不变性（同一个卷积核在所有位置共享）。这些偏置让CNN在小数据上高效，但也限制了它捕捉全局关系的能力——这正是Transformer的优势所在。
