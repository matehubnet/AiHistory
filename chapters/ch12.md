# 第12章：预训练语言模型——从BERT到GPT（2018–2019）

2018年是自然语言处理的转折点。在这一年之前，NLP的主流范式是"针对特定任务收集标注数据，训练特定模型"。每个任务——情感分析、命名实体识别、问答、翻译——都需要自己的模型和数据。

2018年之后，范式变成了"在大规模无标注文本上预训练通用语言模型，然后在特定任务上微调"。同一个预训练模型，微调后可以做好几十个不同的NLP任务。

这个范式转变的核心是两个模型：BERT和GPT。它们用同一个Transformer架构，但选择了相反的方向——BERT用编码器（双向），GPT用解码器（单向）。后来的历史证明，GPT的生成路线走对了。

---

## 词表示的进化：从静态到动态

### Word2Vec（2013）：静态词向量

Mikolov的Word2Vec是词表示的里程碑。它把每个词映射到一个固定维度的向量（通常300维），使得语义相近的词在向量空间中距离相近：

```
向量("国王") - 向量("男人") + 向量("女人") ≈ 向量("女王")
向量("巴黎") - 向量("法国") + 向量("中国") ≈ 向量("北京")
```

这些"词向量类比"在2013年引起了巨大轰动。但Word2Vec有一个根本局限：**每个词只有一个向量**。"苹果"在"吃苹果"和"苹果公司"里是同一个向量——它无法区分多义词。

### ELMo（2018）：上下文相关的词表示

ELMo（Embeddings from Language Models）解决了多义词问题。它用双向LSTM语言模型生成词表示——同一个词在不同上下文中得到不同的向量：

```
"我吃了一个苹果" → ELMo("苹果") = 向量A（水果语义）
"苹果发布了新手机" → ELMo("苹果") = 向量B（公司语义）
```

ELMo是一个重要进步，但它有两个问题：1）双向LSTM训练慢；2）ELMo的表示是"浅层融合"——把前向和后向LSTM的输出拼接，而不是真正的双向交互。

## GPT-1（2018）：自回归预训练的起点

### 前因

OpenAI的思路：如果Transformer能做翻译（序列到序列），那能不能让它先学会"理解语言"再做具体任务？具体来说，用Transformer解码器做语言模型——预测下一个词——然后在下游任务上微调。

### 原理：自回归语言模型

GPT用Transformer解码器做自回归语言模型：

```
给定 "The cat sat on the"，预测下一个词的概率分布 P("mat" | "The cat sat on the")
```

训练目标：最大化训练语料中每个词的对数概率：

```
L = Σ log P(wt | w1, w2, ..., wt-1)
```

这就是"预测下一个词"——一个简单到令人怀疑的目标。但它的优势在于：**不需要任何标注数据**。互联网上有几乎无限量的文本——维基百科、书籍、新闻、网页——都可以用来训练。你只需要让模型预测下一个词，不需要人标注任何东西。

GPT-1有1.17亿参数，在BooksCorpus（约7000本书）上预训练。

### 预训练+微调的范式

预训练完成后，在下游任务上微调。微调方式取决于任务类型：

- 分类：在最后加一个线性分类头
- 相似度：把两个输入的表示拼接后分类
- 问答：把段落和问题拼接，预测答案的起止位置

GPT-1在12项NLP任务中的9项上达到了当时的最佳水平。这证明了预训练+微调范式的有效性。

---

## BERT（2018）：双向预训练的巅峰

### 前因

GPT-1用单向（从左到右）的Transformer解码器做预训练。但语言理解需要同时看前后文——"银行"在"我去银行存钱"和"河岸的银行"里意思不同，你需要看前后文才能理解。

Google的Jacob Devlin提出了BERT（Bidirectional Encoder Representations from Transformers）：用Transformer编码器做双向预训练。

### 原理：掩码语言模型

BERT的预训练任务不是"预测下一个词"（那是单向的），而是"预测被遮住的词"（这是双向的）：

```
输入："The [MASK] sat on the [MASK]"
目标：预测第一个MASK="cat"，第二个MASK="mat"
```

随机遮住15%的词，让模型根据上下文预测。因为被遮住的词可以从左右两边获取信息，所以这是真正的双向预训练。

BERT还用了第二个预训练任务——下一句预测（NSP）：给定两个句子A和B，预测B是否是A的下一句。这帮助模型学习句子间的关系。

### 结果

2018年10月发布时，BERT横扫11项NLP基准测试。在很多任务上，BERT比之前最佳结果提升了好几个百分点——在NLP领域这是罕见的巨大飞跃。

BERT有两个版本：
- BERT-Base：12层，1.1亿参数
- BERT-Large：24层，3.4亿参数

### BERT vs GPT-1

| | BERT | GPT-1 |
|---|------|-------|
| 架构 | Transformer编码器 | Transformer解码器 |
| 预训练 | 掩码语言模型（双向） | 自回归语言模型（单向） |
| 优势 | 理解任务更强 | 生成能力更强 |
| 参数 | 3.4亿（Large） | 1.17亿 |

2018年的共识是BERT更好——因为当时评估的大多是理解任务（分类、问答、NER），BERT的双向注意力在这些任务上天然有优势。

## GPT-2（2019）：更大就是更好

### 前因

GPT-1证明了预训练+微调有效，但参数量只有1.17亿。OpenAI的假设：也许问题只是不够大。

### 原理

GPT-2的架构跟GPT-1几乎相同，但规模大幅提升：15亿参数，训练数据是WebText（约800万网页，40GB文本）。

GPT-2的关键发现：**当模型足够大时，微调可能不需要了**。GPT-2可以通过精心设计的提示词（prompt）直接做任务，不需要修改任何参数——这就是零样本学习（Zero-shot Learning）。

```
翻译任务：提示 "Translate English to French: Hello" → GPT-2输出 "Bonjour"
问答任务：提示 "Who is the president of France? The president of France is" → "Emmanuel Macron"
```

### 后果

GPT-2生成的文本连贯到令人不安。OpenAI以"可能被用于大规模虚假信息"为由，最初只发布了小版本（1.17亿参数），完整模型（15亿参数）延迟发布。这被称为"有限发布"策略，引发了关于AI安全和开放科学的大辩论。

GPT-2的零样本能力虽然令人兴奋，但还很弱——在大多数任务上远不如BERT微调后的效果。但它暗示了一个方向：**如果继续增大模型，零样本能力可能越来越强**。

## 两条路线的分野：理解 vs 生成

2018-2019年，NLP领域形成了两条路线：

- **BERT路线**（理解）：用编码器做双向预训练，在理解任务上微调。代表：BERT、RoBERTa、ALBERT、ELECTRA。
- **GPT路线**（生成）：用解码器做自回归预训练，直接用提示词做任务。代表：GPT-1、GPT-2。

当时的共识是BERT路线更好——因为理解任务更多、更重要，BERT在这些任务上表现更好。

但历史证明GPT路线走对了。原因有三：

1. **规模法则**：GPT路线的零样本/少样本能力随规模增长持续提升，BERT路线的微调性能在中等规模就接近饱和。

2. **任务统一性**：GPT路线用同一个生成目标统一所有NLP任务——翻译、摘要、问答、对话都是"生成下一个词"。BERT路线需要为不同任务设计不同的微调方式。

3. **涌现能力**：当GPT路线的模型大到一定程度，出现了BERT路线不可能有的能力——In-context learning、思维链推理、代码生成。这些能力不是微调出来的，而是从大规模预训练中涌现的。

到2020年GPT-3发布时，这个判断就变得很清楚了。但2019年，大多数人还认为BERT路线才是正道。

---

## 本章技术要点

1. **词表示的进化**：One-hot → Word2Vec（静态）→ ELMo（上下文相关）→ BERT/GPT（深度上下文化）。每一步都让词的表示更精确地反映它在当前语境中的含义。

2. **GPT的自回归预训练**：预测下一个词，不需要标注数据，可以用互联网上的海量文本训练。简单但强大的训练目标。

3. **BERT的掩码语言模型**：随机遮住词让模型预测，真正的双向预训练。在理解任务上显著优于GPT-1。

4. **预训练+微调范式**：先在大规模无标注数据上预训练通用模型，再在特定任务上微调。这取代了"每个任务从头训练"的旧范式。

5. **两条路线的分化**：BERT（编码器/理解/微调）vs GPT（解码器/生成/提示词）。当时BERT被认为更好，但GPT路线随规模增长展现了更强的潜力——生成是更通用的能力，理解是生成的特例。
