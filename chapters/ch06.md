# 第6章：深度学习的种子（2000s）

2006年，多伦多大学计算机科学系的地下室里，Geoffrey Hinton和他的学生Simon Osindero、Teh Yee-Whye发表了一篇论文：《A Fast Learning Algorithm for Deep Belief Nets》。这篇论文没有提出任何全新的数学工具——它用的是1980s就有的受限玻尔兹曼机（RBM），训练方法也是已知的对比散度（CD）算法。

但这篇论文做了一件关键的事：它证明了**深层网络是可以训练的**，只要你用对方法。

这个"对的方法"就是逐层预训练（Layer-wise Pre-training）。

---

## 逐层预训练：绕过梯度消失的工程技巧

### 问题回顾

第4章讲过，梯度消失是深层网络训练的核心障碍。用反向传播直接训练一个5层以上的网络，靠近输入的层几乎学不动——梯度衰减到接近零。

Hinton的思路是：**不要直接训练整个网络，而是一层一层地训练**。

### RBM与对比散度

受限玻尔兹曼机（Restricted Boltzmann Machine，RBM）是一个两层网络：可见层v和隐藏层h，层内无连接（"受限"的含义），层间全连接。

```
可见层 v: v₁ v₂ v₃ ... vₙ
           ↕  ↕  ↕      ↕
隐藏层 h: h₁ h₂ h₃ ... hₘ
```

RBM定义了一个概率分布：

```
P(v, h) ∝ exp(-E(v, h))
E(v, h) = -a'v - b'h - v'Wh
```

训练RBM的目标是让P(v)接近数据的分布。训练规则（对比散度，CD-k）：

```
ΔW ∝ <v·h'>_data - <v·h'>_reconstruct
```

即：数据中的v和h的相关性 - 模型重构后的v和h的相关性。让模型"重构"数据的能力越来越强。

### 逐层预训练的流程

1. 把第一层训练成RBM，让它学会从原始数据中提取第一层特征
2. 把第一层的隐藏层输出当作新的"数据"，训练第二个RBM，提取第二层特征
3. 重复，直到所有层都预训练完
4. 把所有RBM"展开"成一个深层网络，用反向传播微调整个网络

```
原始数据 → [RBM1: 学特征1] → 特征1 → [RBM2: 学特征2] → 特征2 → [RBM3: 学特征3]
                                                      ↓
展开成深层网络: 输入 → 层1 → 层2 → 层3 → 输出
                                                      ↓
反向传播微调: 全网络fine-tune
```

**为什么这能绕过梯度消失？** 因为每一层的预训练是独立的——训练第k层时，只需要一个RBM（两层网络），不存在深层梯度消失的问题。预训练完成后，各层已经有了合理的初始权重，微调时梯度消失的影响大大减轻——因为权重不是从随机状态开始，而是从一个"已经大致正确"的状态开始。

### 后果

Hinton用这个方法在MNIST手写数字数据集上训练了一个4层网络，错误率降到了1.2%——跟当时最好的SVM结果相当，而且用的是端到端学习，不需要手工特征。

更重要的是，"Deep Learning"这个词开始流行。2006年之前，"neural networks"这个词带有负面色彩（两次AI寒冬的阴影）。Hinton重新包装了"多层神经网络"，给它起了新名字，也给了它新的合法性。

但逐层预训练本身并不是最终方案。它是一个过渡性的工程技巧——证明了"深度"是可行的，但方法本身太慢、太复杂。后来，ReLU激活函数、Batch Normalization、残差连接等更优雅的方案直接解决了梯度消失问题，逐层预训练就被淘汰了。

逐层预训练的历史意义不在于方法本身，而在于它**打破了"深层网络训练不动"的共识**，给了人们继续探索深度的信心。

## GPU计算：游戏显卡变成通用计算引擎

2007年，Nvidia发布了CUDA（Compute Unified Device Architecture）——一个让GPU可以用于通用计算的编程接口。

在此之前，GPU是专门做图形渲染的。它的架构设计为并行计算优化——成百上千个简单的计算核心同时工作，每个核心做同样的操作但处理不同的数据（SIMD，Single Instruction Multiple Data）。这种架构非常适合图形渲染中的像素级并行操作，但不适合通用计算——因为你无法用C语言直接编程GPU。

CUDA改变了这一点。它提供了一套C语言的扩展，让程序员可以直接在GPU上写通用代码。突然之间，GPU的巨大并行算力对任何需要大规模并行计算的应用都开放了——包括神经网络的训练。

### 为什么GPU对神经网络训练如此重要

神经网络训练的核心操作是**矩阵乘法**：

```
h = W · x + b
```

其中W是m×n的权重矩阵，x是n×1的输入向量。这个运算需要m×n次乘法和m×n次加法。

在CPU上，这些运算串行执行——一个一个算。在GPU上，m个输出可以并行计算——m个核心同时工作，速度提升m倍。

对于一个有1000个隐藏神经元的层，GPU理论上可以1000倍速。实际上由于内存带宽、核心利用率等因素，典型加速比在10-100倍之间。但这已经足够让"训练数周"变成"训练数小时"。

### 从CUDA到深度学习框架

CUDA是底层接口，直接用它写神经网络训练代码非常繁琐。2012年之后，一系列深度学习框架相继出现，把GPU加速封装成简单易用的API：

- Theano（2010）：蒙特利尔大学的学术框架，第一个自动微分+GPU加速
- Caffe（2013）：贾扬清在UC Berkeley开发，专注于计算机视觉
- TensorFlow（2015）：Google开发，工业级框架
- PyTorch（2016）：Meta开发，动态计算图，更Pythonic

这些框架让研究者不再需要手写CUDA代码，只需要定义网络结构，框架自动处理GPU加速和反向传播。这大大降低了深度学习的使用门槛。

## ImageNet：数据比算法更重要

2009年，斯坦福大学的李飞飞团队发布了一个数据集，叫ImageNet。

ImageNet包含1400多万张图像，涵盖2万多个类别，每张图像都有人工标注的标签。这是当时最大、最全面的大规模图像数据集。

### 为什么ImageNet重要

在ImageNet之前，图像识别领域的数据集很小——Caltech-101只有9000多张图像，PASCAL VOC只有约11000张。在这些小数据集上，SVM和手工特征已经接近饱和，深度学习没有明显的优势。

ImageNet改变了一切。它足够大，大到只有能从数据中自动学习特征的模型才能充分利用它。手工特征（SIFT、HOG）在百万级数据上的表现远不如端到端的深度学习——因为手工特征的设计者不可能预见到所有需要识别的视觉模式。

李飞飞团队的远见在于：**他们不追求算法创新，而是追求数据规模**。在2006-2007年，大部分AI研究者在研究更好的算法，很少有人认为"更大的数据集"才是关键。李飞飞花了三年时间组织这个数据集——用Amazon Mechanical Turk雇佣大量人工标注者，逐张图片标注类别。这在当时被认为是一个"没有学术价值"的工程性工作。

但ImageNet后来成为深度学习爆发的触发器。2010年开始的ImageNet大规模视觉识别挑战赛（ILSVRC）成为计算机视觉领域的年度盛事，也是2012年AlexNet横空出世的舞台。

---

## 三个要素就位

到2009年，深度学习爆发的三个必要条件已经全部就位：

1. **算法突破**：逐层预训练（2006）证明了深层网络可以训练。虽然方法本身后来被淘汰，但它打破了"深度不可行"的心理障碍。

2. **算力**：CUDA（2007）让GPU可以用于神经网络训练。Alex Krizhevsky在2012年用两块GTX 580显卡训练AlexNet——这在2007年之前是不可能的。

3. **数据**：ImageNet（2009）提供了足够大的数据集，让深度学习有足够的信息来学习特征。

这三个要素缺一不可。没有算法突破，人们不敢尝试深层网络。没有GPU，训练深层网络太慢。没有大数据，深层网络会过拟合。

回顾第3章的三重困境——算力不够、数据不够、话语权在符号AI——你会发现，前两个困境已经被技术进步解决，第三个困境将在2012年被AlexNet的压倒性胜利彻底打破。

---

## 本章技术要点

1. **逐层预训练**：用RBM逐层训练深层网络，再整体微调。绕过梯度消失的工程技巧，证明了"深度"可行。方法本身后来被ReLU、BatchNorm、残差连接等更优雅的方案取代，但它的历史意义在于打破共识。

2. **GPU加速**：CUDA让GPU从图形渲染专用变成通用计算引擎。神经网络的矩阵乘法天然适合GPU并行。典型加速10-100倍，让"训练数周"变成"训练数小时"。

3. **ImageNet的远见**：1400万张图像、2万类别的大规模数据集。数据规模比算法创新更重要——这个反直觉的洞见是深度学习爆发的关键前提。

4. **三要素框架**：算法+算力+数据，三者缺一不可。这个框架不仅解释了2012年的爆发，也解释了之前两次AI寒冬的根因——缺了其中任何一个，深度学习都无法成功。

5. **"Deep Learning"的命名**：Hinton把"多层神经网络"重新包装为"深度学习"，摆脱了两次AI寒冬的负面联想。命名不是小事——它改变了人们对这个方向的认知框架。
