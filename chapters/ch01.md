# 第1章：机器能思考吗？（1940s–1950s）

1950年的秋天，曼彻斯特的雨季来得比往年更早。阿兰·图灵走在维多利亚公园的长廊下，口袋里揣着一份刚写完的论文手稿。这篇论文没有一个公式是关于计算机器的制造的——它问的是一个更根本的问题：机器能思考吗？

这个问题看似简单，实则凶险。因为它逼迫你先回答另一个问题：什么是"思考"？如果你无法定义它，你怎么判断一台机器是否做到了它？图灵知道这个困境，于是他做了一个工程师式的决定——绕过定义，只看行为。

## 图灵测试：绕过哲学的行为主义

图灵在《计算机器与智能》（Computing Machinery and Intelligence，1950）中提出的不是"思考的定义"，而是一个实验：让一个人通过文字对话与两个隐藏的对话者交流，一个是人，一个是机器。如果这个人无法可靠地分辨谁是人谁是机器，那么我们就应该说这台机器具有智能。

这个设计有几个值得深想的特征：

1. **它把智能从"内在状态"转向了"外在行为"**。你不需要知道机器内部在做什么，只需要看它对外部的反应。这跟后来整个AI领域的技术路线惊人一致——我们至今训练模型时也是看输出、不看过程。

2. **它把智能从"全知全能"转向了"特定场景"**。图灵没说机器要在所有场景下都跟人一样，只说在对话这个场景下能骗过去就行。这为后来"窄AI"（Narrow AI）的合法性留下了空间。

3. **它隐含了一个危险的假设**：行为等价=智能等价。如果一台机器在对话中表现得像人，我们就认为它"思考"了。这个假设后来被John Searle的"中文房间"论证狠狠质疑，但那是几十年后的事了。

图灵在论文中还预判了几个常见的反对意见——"机器不会犯错""机器没有意识""机器不能做真正的新事"——并逐一反驳。他特别指出，"机器不能做真正的新事"这个反对意见隐含了一个对人类思维的浪漫化：人类所谓的"创新"很多时候不过是随机变异加上选择保留，这完全可以用机器模拟。

但图灵真正深刻的地方在于他对未来的预测。他估计到2000年，计算机的存储容量达到约10⁹位，一台拥有足够存储的机器经过适当编程后，能在5分钟的图灵测试中有30%的概率骗过裁判。这个预测的时间线比实际发生晚了大约十年，但"骗过裁判"这件事的确发生了——2023年，ChatGPT在许多对话场景中远不止30%的概率。

图灵没能看到这一天。1952年，他因同性恋行为被英国政府定罪，被迫接受化学阉割。1954年6月7日，41岁的图灵在威姆斯洛的家中吃下了一口沾有氰化物的苹果。

## McCulloch-Pitts神经元：第一次用数学描述"神经计算"

图灵提出的是一个哲学框架。而1943年，沃伦· McCulloch和沃尔特· Pitts做了一件更具体的事：他们用数学描述了一个神经元是怎么工作的。

McCulloch是一位神经生理学家，Pitts是一位20岁的数学天才（他15岁就读了《数学原理》并写信给Carnap指出错误，Carnap以为他是研究生）。两人在芝加哥相遇，合作写出了《A Logical Calculus of the Ideas Immanent in Nervous Activity》（1943）。

他们的模型极其简洁：

- 一个神经元接收多个输入，每个输入是一个二值信号（0或1）
- 每个输入有一个权重 wᵢ
- 神经元计算加权和 Σ(wᵢ · xᵢ)
- 如果加权和超过阈值θ，神经元输出1；否则输出0

用公式写就是：

```
y = 1  if Σ(wᵢ · xᵢ) ≥ θ
y = 0  if Σ(wᵢ · xᵢ) < θ
```

这个模型看似简陋，但McCulloch和Pitts证明了两件重要的事：

1. **任何命题逻辑函数都可以用M-P神经元网络实现**。AND、OR、NOT只是特例——给定任何逻辑表达式，你都可以构造一个M-P网络来计算它。这意味着神经计算和符号逻辑不是对立的，而是同一个数学结构的不同面。

2. **网络可以闭环运行**。当神经元之间形成环路，网络就有了"记忆"——状态可以在环中持续。这预示了后来的循环神经网络（RNN）。

M-P神经元的意义不在于它能模拟真实大脑（它不能），而在于它建立了第一个**计算与神经的桥梁**。它告诉你：你可以用数学工具来描述"神经计算"，并且这种计算是有逻辑意义的。

但M-P神经元有一个致命的局限：它是**固定的**。权重wᵢ和阈值θ是人为设定的，不是从数据中学习来的。一个M-P网络能做什么，完全取决于设计者事先知道什么。这就像一台计算器——它精确，但不灵活。

## 感知机：机器第一次"从数据中学习"

1958年，弗兰克· Rosenblatt在康奈尔航空实验室做了一个突破性的决定：让权重不再是人设定的，而是机器自己学出来的。

Rosenblatt的感知机（Perceptron）在M-P神经元的基础上增加了一个学习规则：

```
wᵢ_new = wᵢ_old + α · (target - output) · xᵢ
```

其中α是学习率（步长），target是正确的标签，output是模型的预测，xᵢ是输入。

这个规则的直觉非常清晰：

- 如果预测对了（target = output），权重不变
- 如果预测错了，就沿着"能让下次更接近正确答案"的方向调整权重

这就是**感知机学习算法**。Rosenblatt证明了一个关键定理：**如果训练数据是线性可分的，感知机学习算法会在有限步内收敛**——一定能找到一个完美分类所有训练数据的权重组合。

什么叫"线性可分"？几何直觉最直观：在二维空间里，如果两类点可以被一条直线完美分开，它们就是线性可分的。在更高维度里，这条线变成一个超平面。

```
     ● ● ●          ○ ○ ○
     ● ● ●          ○ ○ ○
     ● ● ● -------- ○ ○ ○    ← 超平面把它们完美分开
     ● ● ●          ○ ○ ○
```

线性可分时，感知机完美工作。这个证明让整个领域兴奋起来——机器真的可以自己学会分类！

Rosenblatt不仅有理论，还有硬件。他在IBM 704上实现了感知机，后来又做了一个专用的感知机硬件MARK I，用光电传感器做输入，用电位器做可调权重，能识别简单的图像。媒体报道说这台机器"像人一样学习"，《纽约时报》写道："海军展示了一台电子计算机的胚胎，期望它以后能走路、说话、看、写、自我复制，并意识到自己的存在。"

这是AI史上第一次大规模的公众热情爆发。但这种热情里有一种危险的倾向——人们把感知机的成功泛化为"所有问题都可以这样解决"。

## 早期AI的乐观：Logic Theorist与"AI近在眼前"

感知机不是1950s唯一的AI成就。1955年，Allen Newell和Herbert Simon在RAND公司开发了Logic Theorist——一个能自动证明数学定理的程序。

Logic Theorist做的事情很具体：它从《数学原理》（Principia Mathematica）中取定理，然后用启发式搜索（heuristics）寻找证明路径。它成功证明了38个定理中的52个（其中一些证明比原书中的更优雅）。

Logic Theorist的技术路线跟感知机完全不同：

- 感知机是**数据驱动的**——从样本中学习模式
- Logic Theorist是**知识驱动的**——用符号逻辑和启发式规则做推理

这两条路线的分歧贯穿了整个AI历史。前者后来演化为连接主义→深度学习→大模型；后者演化为符号主义→专家系统→神经符号融合。它们各自的兴衰周期构成了这本书的主线。

1956年的达特茅斯会议（Dartmouth Conference）把"Artificial Intelligence"这个词正式推上了舞台。组织者John McCarthy、Marvin Minsky、Allen Newell和Herbert Simon在提案中写道：

> "这项研究基于这样的假设：学习的每一个方面或智能的任何其他特征原则上都可以被精确描述，以至于可以制造一台机器来模拟它。"

注意这个假设的力度——"每一个方面""任何其他特征""原则上都可以"。这不是一个谨慎的科学假设，这是一个近乎哲学的宣言：智能的全部都可以被形式化。

参会者中有人预测"一代人之内"就会创造出与人类智能匹敌的机器。美国政府投入了数百万美元资助AI研究。

今天回头看，这个乐观显然过头了。但理解这种乐观的根源很重要——它不是盲目的，而是基于一种合理的类比：计算机已经在数值计算上远超人类，为什么推理和学习不能是下一个被征服的领域？

问题在于，数值计算是一个规则完全清晰、输入输出定义明确的任务。而"智能"不是。智能涉及模糊性、上下文、常识、创造力——这些东西的规则并不"原则上可以被精确描述"。这个教训花了二十年才被深刻认识到。

## 本章技术要点

1. **图灵测试的核心思想**：智能应该从外在行为来判断，而非内在机制。这个行为主义思路贯穿了整个AI评估体系——今天的benchmark本质上都是图灵测试的变体。

2. **M-P神经元**：第一个用数学描述神经计算的模型。关键贡献是证明逻辑计算可以用神经元网络实现，开创了"计算神经"这个研究方向。局限是权重固定，不能学习。

3. **感知机学习算法**：第一个让机器从数据中自动学习的算法。核心是权重更新规则 wᵢ_new = wᵢ_old + α(target - output)xᵢ，在数据线性可分时保证有限步收敛。

4. **线性可分性**：感知机的能力边界——它只能解决线性可分的分类问题。这个看似简单的限制后来成为神经网络第一次崩塌的核心原因（第2章）。

5. **两条路线的起源**：感知机（数据驱动/学习）vs Logic Theorist（知识驱动/推理），这两条路线的竞争、融合、再竞争构成了AI技术演化的主旋律。

6. **乐观的根源与教训**：1950s的AI乐观基于"计算已经征服数值，下一步征服推理"的类比。教训是：智能的任务定义远比数值计算模糊，"原则上可以被精确描述"是一个过强的假设。
