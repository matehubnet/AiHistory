# 第3章：暗流涌动——被低估的早期思想（1960s–1970s）

当主流AI界在为符号系统和感知机争论不休的时候，有几股暗流在安静地流动。这些工作在当时的学术格局中几乎没有影响力——论文引用寥寥，经费申请被拒，研究者常常被当作边缘人。但几十年后回头看，正是这些"暗流"定义了AI真正的未来。

---

## 反向传播的萌芽：Werbos与链式法则（1974）

Paul Werbos在1974年的哈佛博士论文中做了一件后来改变世界的事：他展示了如何用链式法则（chain rule）计算多层神经网络中每个权重的梯度，从而让多层网络可以被训练。

这个想法的起点是一个具体的问题：**感知机是单层的，多层网络理论上能解决XOR，但没有训练方法**。Werbos想知道：能不能找到一种系统化的方法，计算"每个权重对最终误差的贡献有多大"，然后据此调整权重？

答案藏在微积分的链式法则中。

### 链式法则的直觉

假设你有一个简单的计算链：

```
x → [f] → a → [g] → b → [h] → y
```

其中f、g、h是三个函数，a = f(x)，b = g(a)，y = h(b)。你想知道x对y的影响有多大，即dy/dx。

链式法则说：

```
dy/dx = (dy/db) · (db/da) · (da/dx)
```

也就是：**把每一步的局部梯度乘起来，就得到了从输入到输出的全局梯度**。

把同样的逻辑应用到多层神经网络：

```
输入x → [层1: w₁] → h₁ → [层2: w₂] → h₂ → [层3: w₃] → 输出y
损失 L = loss(y, target)
```

你想知道w₁对损失L的影响：dL/dw₁。链式法则说，从L出发，沿着网络反向走，把每一步的局部梯度乘起来。

```
dL/dw₁ = (dL/dy) · (dy/dh₂) · (dh₂/dh₁) · (dh₁/dw₁)
```

这就是**反向传播**（Backpropagation）——从输出向输入反向传播梯度。

### 为什么这很重要？

在Werbos之前，人们知道多层网络更强大，但不知道怎么训练。Werbos证明了：**多层网络的梯度可以系统地计算出来**。这意味着，给定一个损失函数，你可以精确地知道每个权重应该往哪个方向调整才能减小损失。

但Werbos的论文几乎没被注意到。几个原因：

1. **时机不对**。1974年，Minsky和Papert的《Perceptrons》刚出版5年，神经网络研究还在低谷。没人想听"多层网络可以训练"这种消息。

2. **学术圈隔阂**。Werbos的论文在哈佛统计系完成，而AI研究者主要集中在MIT、斯坦福、CMU的计算机系。跨圈子的传播很慢。

3. **缺乏实验验证**。Werbos做了理论推导，但当时没有足够的算力在非平凡规模上验证它。没有实验结果，理论很难引起注意。

直到1986年，Rumelhart、Hinton和Williams在Nature上发表论文，重新发现并用实验验证了反向传播算法，这个方法才真正被广泛认知。Werbos的工作被追溯认可，但那已经是12年后了。

## Boltzmann机与Hopfield网络：物理学给神经网络的礼物

1980s之前，还有另一股暗流：物理学家开始对神经网络感兴趣。

### Hopfield网络（1982）

John Hopfield是加州理工的物理学家。1982年，他提出了一个以自己名字命名的网络模型。Hopfield网络的灵感来自物理学中的自旋玻璃（spin glass）——一种磁性材料的无序状态。

Hopfield网络的关键思想：**给网络定义一个"能量函数"，网络的状态演化就是能量下降的过程**。

```
E = -Σᵢ<ⱼ wᵢⱼ · sᵢ · sⱼ
```

其中sᵢ是神经元的状态（+1或-1），wᵢⱼ是连接权重。

网络会自发地演化到能量最低的状态——即"最稳定"的配置。Hopfield证明了这个能量函数是李雅普诺夫函数（只会下降不会上升），所以网络一定会收敛到某个稳定状态（吸引子）。

这个性质有一个绝妙的应用：**内容可寻址记忆**（Content-Addressable Memory）。你把一个模式存入网络（设置权重使其成为吸引子），之后只要给网络一个"部分正确"或"带噪声"的输入，网络就会自动演化到最近的存储模式——它"回忆"出来了。

这跟传统计算机的内存完全不同。传统内存是"地址→内容"：你必须知道确切的地址才能读取。Hopfield网络是"部分内容→完整内容"：你只需要记得大概，网络就能帮你补全。这更接近人类的记忆方式——你不需要记住一个人的每个细节才能认出他。

### Boltzmann机（1985）

Hopfield网络有一个问题：它只能记住模式，不能学习新模式（权重需要事先设置）。Geoffrey Hinton和Terrence Sejnowski在1985年提出了Boltzmann机，把统计物理学的方法引入神经网络。

Boltzmann机的名字来自统计力学中的Boltzmann分布：

```
P(state) ∝ exp(-E(state) / T)
```

其中E是能量，T是"温度"。温度高时，系统随机跳转，探索更多状态；温度低时，系统倾向于待在低能量状态。

Boltzmann机的核心创新：它用**模拟退火**（Simulated Annealing）来训练——从高温开始（大量随机探索），逐渐降温（收敛到好的解）。训练规则是：

```
Δwᵢⱼ = η · (<sᵢ·sⱼ>_data - <sᵢ·sⱼ>_model)
```

即：权重调整量 = 学习率 × (数据中的相关性 - 模型产生的相关性)。让模型产生的统计分布尽量接近数据的统计分布。

这个训练规则在理论上很优雅，但有一个严重的实际问题：**计算< sᵢ·sⱼ >_model需要马尔可夫链蒙特卡洛（MCMC）采样，非常慢**。这在当时基本不可行，除了最简单的网络。

Boltzmann机的意义更多是概念性的：它建立了一种**概率生成模型**的思路——模型不是学习输入到输出的映射，而是学习数据本身的概率分布。这个思路后来在变分自编码器（VAE）、扩散模型（Diffusion Models）中得到了延续。

## 统计模式识别的另一条路

在符号AI和神经网络都陷入困境的时候，第三条路线在安静地生长：**统计模式识别**。

这条路线的哲学很简单：不假设你知道数据的结构（符号AI的做法），也不假设你需要模仿大脑（神经网络的做法），而是**直接从数据中估计统计关系**。

1960s-1970s的关键进展：

### 贝叶斯决策论

给定两类数据，每类有一个条件概率分布P(x|类别)，最优分类规则是：

```
选择类别 = argmax P(类别|x) = argmax P(x|类别) · P(类别)
```

这就是贝叶斯定理的直接应用。它给出了分类问题在统计意义上的最优解——不可能比贝叶斯分类器错误率更低。

### Fisher判别分析

Ronald Fisher在1936年提出的线性判别分析（LDA）是一种有统计理论保证的分类方法：找到让"类间方差最大、类内方差最小"的投影方向。这个方法在数据满足高斯分布假设时是最优的。

### 最近邻分类

最简单的分类方法：给一个新样本，在训练集中找到离它最近的样本，把新样本归为同一类。Cover和Hart在1967年证明了一个惊人的结果：**最近邻分类器的错误率不超过贝叶斯最优错误率的两倍**。这意味着，即使你完全不知道数据的分布，最近邻方法也不会差太远。

这些工作的共同特点是：**不需要假设数据的结构，只需要数据本身**。它们是纯数据驱动的，跟符号AI的"知识编码"和神经网络的"模拟大脑"都不同。

但这些方法也有明显的局限：它们在低维空间效果好，但面对高维数据（如图像的每个像素都是一个维度），就遇到了**维度灾难**（Curse of Dimensionality）——数据在高维空间中变得极其稀疏，统计估计不可靠。

这个问题的解决方案后来分成了两条路：一条是手工设计好的低维特征（SIFT、HOG等），把高维数据压缩到有意义的低维空间——这就是1990s-2000s的特征工程时代；另一条是让模型自动学习特征表示——这就是深度学习的路线。

## 为什么这些工作被忽视？

回到本章的核心问题：为什么Werbos的反向传播、Hopfield网络、Boltzmann机和统计方法在1960s-1970s几乎没有影响力？

三个原因：

1. **算力不够**。反向传播需要多次前向-反向传播迭代训练多层网络。1970s的计算机训练一个几十个神经元的小网络可能需要几小时。Boltzmann机的MCMC采样更慢。算力不足让这些方法在非平凡问题上无法展示效果。

2. **数据不够**。统计方法需要大量数据才能可靠估计概率分布。1970s没有互联网，没有大规模数字化数据集。MPEG、JPEG标准还没出现，图像都是胶片的。没有数据，再好的方法也跑不起来。

3. **话语权在符号AI**。1970s的AI学界由MIT、斯坦福、CMU的符号AI研究者主导。他们对"学习"路线持怀疑态度，认为符号推理才是正道。资金分配、期刊发表、会议录用都受这种偏好影响。

这三重困境——算力、数据、话语权——形成了一个负反馈循环：没有成果→没有经费→没有进展→更没有成果。

打破这个循环需要三个条件同时满足：算法突破（让方法在有限算力下可用）、算力突破（让训练实际可行）、数据突破（让模型有足够的信息学习）。这三个条件要到2000s才逐步汇聚，在2012年最终引爆。

但那些在暗流中坚持的研究者——Hinton、LeCun、Bengio——他们在这几十年里做了两件关键的事：一是持续改进算法，让方法越来越高效；二是培养了一批学生，保留了知识传承。当条件成熟时，他们已经在起跑线上了。

---

## 本章技术要点

1. **反向传播的数学本质**：链式法则在计算图上的应用。从输出向输入反向传播梯度，可以精确计算每个权重对损失的影响。这是训练多层网络的基础。

2. **Hopfield网络**：能量函数+吸引子模型，实现了内容可寻址记忆。从"部分内容"恢复"完整内容"的方式更接近人类记忆。

3. **Boltzmann机**：概率生成模型的先驱。学习数据的概率分布而非输入输出映射，这个思路在VAE、扩散模型中延续。训练需要MCMC采样，当时太慢。

4. **统计模式识别**：纯数据驱动的第三条路线。贝叶斯决策论给出最优分类器，最近邻方法有理论保证，但都受限于维度灾难。

5. **被忽视的三重原因**：算力不够、数据不够、话语权在符号AI。这三重困境形成负反馈循环，直到2000s三个条件同时满足才打破。

6. **暗流中的坚持者**：Hinton、LeCun、Bengio在低谷期持续改进算法和培养学生。当条件成熟时，他们已经在起跑线上。这是科学史上"在无人关注的领域长期坚持"的经典案例。
