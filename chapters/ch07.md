# 第7章：AlexNet时刻——深度学习登上舞台（2012）

2012年9月30日，ImageNet大规模视觉识别挑战赛（ILSVRC 2012）的结果公布。一个叫AlexNet的模型把top-5错误率从上一年的25.8%降到了16.4%——一个10个百分点的飞跃。第二名用的是SIFT+Fisher Vector+SVM的组合，错误率是26.2%。

这不是一个量变。在ImageNet竞赛的历史上，年度进步通常是1-2个百分点。AlexNet一步跨了10个点。整个计算机视觉领域在接下来的两年里全面转向深度学习。

这个时刻后来被称为"AlexNet时刻"——一个领域被一个结果彻底改变方向的历史瞬间。

---

## 为什么是AlexNet——而不是更早的LeNet

AlexNet不是第一个卷积神经网络。Yann LeCun在1998年就发表了LeNet-5——一个7层的CNN，用于手写数字识别，在美国邮政系统的支票识别中实际部署。

### LeNet-5回顾

LeNet-5的架构：

`
输入(32x32) → Conv(6@28x28) → Pool(6@14x14) → Conv(16@10x10) → Pool(16@5x5) → FC(120) → FC(84) → 输出(10)
`

- 卷积层提取局部特征（边缘、纹理）
- 池化层降低空间分辨率，增加位置不变性
- 全连接层做最终分类

LeNet-5在MNIST上的错误率是0.8%，在当时是最好的。但LeNet-5只能处理32x32的小图像，只有6万张训练图像，网络只有7层。

### AlexNet vs LeNet：什么变了

AlexNet的架构本质上就是放大版的LeNet——更多层、更多神经元、更大输入。但这个"放大"只有在三个条件同时满足时才有意义：

| 条件 | LeNet时代(1998) | AlexNet时代(2012) |
|------|-----------------|-------------------|
| 数据 | MNIST: 6万张 | ImageNet: 150万张 |
| 算力 | CPU | 2xGTX 580 GPU |
| 算法 | Sigmoid激活 | ReLU + Dropout |

没有150万张图像，AlexNet会过拟合。没有GPU，AlexNet训练太慢。没有ReLU和Dropout，AlexNet训练不动。

AlexNet的架构：

`
输入(227x227x3) → Conv(96@55x55) → Pool → Conv(256@27x27) → Pool → Conv(384@13x13)
→ Conv(384@13x13) → Conv(256@13x13) → Pool → FC(4096) → FC(4096) → FC(1000) → Softmax
`

60M参数，650K神经元，5个卷积层+3个全连接层。用两块GTX 580训练了5-6天。

## AlexNet的关键技术创新

### ReLU激活函数

AlexNet最重要的改变不是网络更深，而是把激活函数从sigmoid换成了ReLU。

`
Sigmoid: sigma(z) = 1/(1+e^-z)     导数最大0.25
ReLU:    f(z) = max(0, z)           导数：z>0时为1，z<0时为0
`

ReLU解决了梯度消失问题的核心原因：正区间的导数恒为1。梯度在反向传播中不会衰减——不管经过多少层，只要神经元处于激活状态（z>0），梯度就完整传递。

ReLU还有一个实际的好处：计算极快。Sigmoid需要计算指数，ReLU只需要一个比较操作。在百万次前向-反向传播的训练中，这个差异累积起来很显著。

ReLU的缺点：死亡ReLU问题（Dying ReLU）。如果一个神经元的权重使得它对所有输入都输出0（z<=0），它的梯度永远为0，永远无法恢复。实践中用适当的学习率和初始化可以缓解。后来的变体（Leaky ReLU、GELU）在负区间给一个小斜率，进一步缓解这个问题。

### Dropout正则化

AlexNet的60M参数远超训练样本数，过拟合是必然的。Hinton在2012年提出的Dropout是一种优雅的正则化方法：

**训练时**：每个神经元以概率p（通常p=0.5）被随机"关闭"——输出设为0，不参与前向和反向传播。每次前向传播，网络被随机"瘦身"成一个子网络。

**推理时**：所有神经元都参与，但输出乘以p（或等价地，训练时用1/p缩放），保持期望输出不变。

Dropout的直觉：它迫使每个神经元不能依赖任何其他特定神经元，因为那些神经元可能随时被关闭。每个神经元必须学会独立有用的特征。这类似于集成方法的思路——每次Dropout相当于训练一个不同的子网络，推理时所有子网络的预测被隐式地平均。

### 数据增强

AlexNet用了两种数据增强方法来扩充训练数据：

1. **随机裁剪+水平翻转**：从256x256的原图中随机裁剪227x227的patch，加上水平翻转，一张图变成2048个变体。
2. **PCA颜色扰动**：对RGB通道做PCA，加上随机扰动，模拟光照变化。

数据增强是深度学习中最实用的技巧之一——它让模型见过更多"看起来不同但语义相同"的图像，提升泛化能力。而且它几乎是免费的——不需要额外标注，只需要对已有图像做变换。

## 从特征工程到特征学习

AlexNet的成功标志着一个范式转变的完成：从"人类设计特征+机器学分类"到"机器自己学特征+自己学分类"。

在特征工程时代，一个典型的图像识别流水线是：

`
图像 → [SIFT/HOG提取] → 特征向量 → [SVM分类] → 标签
         ↑ 人类设计              ↑ 机器学习
`

SIFT/HOG的设计需要人类对视觉的深刻理解——什么特征对识别有用？边缘？颜色？纹理？形状？不同的任务需要不同的特征组合。

在深度学习时代：

`
图像 → [CNN] → 标签
         ↑ 全部由机器学习
`

AlexNet第一层学到的卷积核看起来像Gabor滤波器（边缘检测器）和颜色斑点——跟人类设计的底层特征惊人地相似。但更高层学到的特征是人类很难手工设计的——它们对应着特定的物体部件和空间模式。

**前因**：SIFT+SVM在ImageNet规模的数据上已经饱和，手工特征无法覆盖2万个类别的视觉多样性。

**原理**：CNN自动学习层次化特征+ReLU解决梯度消失+Dropout防止过拟合+GPU加速训练。

**后果**：整个计算机视觉领域在两年内全面转向深度学习。到2014年，ImageNet竞赛的几乎所有参赛队伍都在用CNN。SIFT和HOG在研究论文中被迅速遗忘。

---

## 本章技术要点

1. **AlexNet时刻的本质**：不是AlexNet的架构有多创新（它就是放大版LeNet），而是三个条件终于同时满足——大数据+GPU+ReLU/Dropout。深度学习的爆发是技术成熟度到达临界点的结果。

2. **ReLU的核心贡献**：正区间导数恒为1，解决了sigmoid的梯度消失问题。简单但改变一切的改动。后来的变体（Leaky ReLU、ELU、GELU）都是在这个基础上的微调。

3. **Dropout**：训练时随机关闭神经元，迫使每个神经元独立有用。等价于训练多个子网络并隐式集成。推理时所有神经元参与，输出缩放保持期望不变。

4. **数据增强**：对训练图像做随机变换（裁剪、翻转、颜色扰动），几乎免费地扩充训练数据。深度学习最实用的技巧之一。

5. **范式转变**：从"人类设计特征+机器学分类"到"机器端到端学习"。特征工程的上限被人类认知的盲区限制，特征学习没有这个上限——只要有足够的数据和算力。
