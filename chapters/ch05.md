# 第5章：统计学习的黄金年代（1990s–2000s）

1995年，Vladimir Vapnik在新泽西的AT&T贝尔实验室里做了一个决定。他决定把自己在苏联发展了二十多年的统计学习理论，用一个叫做支持向量机的算法推向世界。

这个决定改变了一切。在接下来的十年里，SVM统治了机器学习。神经网络在角落里苟延残喘，符号AI在专家系统的废墟上收拾残局，而SVM优雅地横扫了一个又一个应用领域。这是统计学习的黄金年代。

---

## SVM：结构风险最小化的杰作

### 为什么SVM出现了——神经网络的不稳定

1990s初的神经网络有几个让人头疼的问题：

1. **训练不稳定**。同样的数据、同样的网络结构，不同的随机初始化可能导致完全不同的结果。你跑10次实验可能得到10个不同的模型。

2. **超参数难调**。学习率、隐藏层大小、层数、正则化系数——这些超参数没有系统化的选择方法，全靠试错和经验。

3. **理论薄弱**。神经网络为什么有效？什么时候会过拟合？没人能给出令人满意的数学解释。对工程师来说，"It works but I can't tell you why"是不可接受的。

学界需要一种**有理论保证、训练稳定、超参数少**的方法。Vapnik的SVM正是为此而生。

### 最大间隔分类——SVM的核心直觉

给定两类数据点，SVM不是随便找一个能把它们分开的超平面，而是找**间隔最大的那个超平面**。

```
        ○ ○ ○
      ○ ○ ○ ○ ○
  ----●---------●----  ← 支持向量（距离超平面最近的点）
      ● ● ● ● ●
        ● ● ●

  ← 间隔最大化 →
```

为什么间隔大更好？Vapnik的理论给出了答案：**间隔越大，泛化误差的上界越小**。这不是经验观察，是数学证明。

具体来说，Vapnik和Chervonenkis在1970s发展了VC维理论，证明了：

```
泛化误差 ≤ 训练误差 + f(VC维 / 样本数)
```

其中f是一个关于VC维和样本数的函数。VC维衡量了模型类"能拟合多复杂的数据"——VC维越高，模型越灵活，也越容易过拟合。

SVM的核心思想是**结构风险最小化**（Structural Risk Minimization）：不只是最小化训练误差（经验风险），还要控制模型复杂度（结构风险），使得泛化误差的上界最小。最大间隔分类器恰好是这个原则的直接实现——间隔越大，等价VC维越低。

### 对偶问题与核技巧

最大间隔分类的原始问题：

```
最小化  ½||w||²
约束    yᵢ(w·xᵢ + b) ≥ 1,  ∀i
```

这是一个凸优化问题（二次规划），有唯一全局最优解——不存在局部最小值。这直接解决了神经网络的"训练不稳定"问题。

通过拉格朗日对偶，原始问题可以转化为对偶问题：

```
最大化  Σαᵢ - ½ΣΣαᵢαⱼyᵢyⱼ(xᵢ·xⱼ)
约束    αᵢ ≥ 0, Σαᵢyᵢ = 0
```

注意对偶问题中，数据点只以**内积** xᵢ·xⱼ 的形式出现。这是一个关键观察——我们可以把内积替换成任何满足Mercer条件的核函数K(xᵢ,xⱼ)，而不需要显式地构造高维映射。

这就是**核技巧**（Kernel Trick）：

```
原始空间中线性不可分 → 映射到高维特征空间 → 在高维中线性可分
但不需要显式计算高维映射！只需要计算核函数K(xᵢ,xⱼ)
```

常用核函数：
- 线性核：K(xᵢ,xⱼ) = xᵢ·xⱼ（不做映射，就是原始SVM）
- 多项式核：K(xᵢ,xⱼ) = (xᵢ·xⱼ + c)ᵈ（映射到d次多项式特征空间）
- RBF核：K(xᵢ,xⱼ) = exp(-γ||xᵢ-xⱼ||²)（映射到无限维特征空间）

RBF核特别优雅——它把数据映射到一个无限维的空间，在这个空间中几乎任何数据都是线性可分的。但SVM的正则化（间隔最大化）防止了过拟合，所以即使在无限维空间中，泛化性能仍然有保证。

**前因**：神经网络不稳定、难调参、理论薄弱，学界需要更有理论保证的方法。

**原理**：最大间隔→对偶问题→核技巧，一套完整的统计学习理论支撑。

**后果**：在中小规模数据上碾压神经网络。手写数字识别（MNIST）、文本分类、生物信息学——SVM成为2000s的默认选择。

## 集成方法：三个臭皮匠顶个诸葛亮

SVM不是统计学习黄金年代唯一的明星。另一条同样成功的路线是**集成方法**（Ensemble Methods）。

### 为什么集成方法出现

单个模型总有一个困境：太简单→欠拟合（捕捉不到数据的复杂规律），太复杂→过拟合（记住了噪声）。有没有一种方法既能捕捉复杂规律，又不容易过拟合？

答案是：**用多个简单模型投票**。

### Bagging与随机森林

Bagging（Bootstrap Aggregating）的思路：

1. 从训练集中有放回地采样，得到多个子训练集
2. 在每个子训练集上训练一个模型（通常是决策树）
3. 最终预测：分类取多数投票，回归取平均

为什么有效？每个模型在采样中看到不同的数据子集，学到不同的规律。它们的误差是不完全相关的——对同一个样本，不同模型可能犯不同的错。多个模型投票时，不相关的误差会相互抵消，留下共同的正确判断。

Breiman在2001年提出的随机森林（Random Forest）在Bagging基础上增加了特征随机性：每个决策树在每个分裂节点只考虑一个随机子集的特征。这进一步降低了树之间的相关性，提升了集成效果。

### Boosting与AdaBoost

Boosting的思路跟Bagging不同。Bagging是让多个模型独立学习、平等投票；Boosting是让多个模型**序列学习**，每个新模型专注于前一个模型犯错的样本。

AdaBoost（Freund & Schapire，1997）的算法：

1. 训练第一个弱分类器h₁
2. 增加h₁分错样本的权重
3. 在加权数据上训练第二个弱分类器h₂
4. 重复，直到足够多弱分类器
5. 最终分类器：加权投票 H(x) = sign(Σαₜhₜ(x))

AdaBoost有一个优美的理论性质：**训练误差随弱分类器数量指数下降**，只要每个弱分类器的准确率略好于随机猜测（>50%）。这意味着即使每个弱分类器都很弱，集成起来可以非常强。

### 集成方法的哲学

集成方法的成功揭示了一个深刻的事实：**在机器学习中，多样性比个体强度更重要**。一个由多个弱但不同的模型组成的集成，往往优于一个单独的强模型。这个原则在后来的深度学习中以不同形式重现——Dropout（随机丢弃神经元，相当于训练多个子网络并集成）就是集成思想在神经网络中的变体。

## 贝叶斯方法的复兴

统计学习的黄金年代还有第三条重要路线：贝叶斯方法的复兴。

### 概率图模型

概率图模型（Probabilistic Graphical Models）把概率论和图论结合起来，用图的结构编码变量之间的条件独立性。

- **有向图（贝叶斯网络）**：编码因果关系。A→B表示"A影响B的概率"。医疗诊断中的疾病-症状网络是典型应用。
- **无向图（马尔可夫随机场）**：编码相关关系。A—B表示"A和B相关"。图像分割中的像素标签网络是典型应用。

概率图模型的优势是**可解释性**——图的结构直接反映了变量之间的关系，你可以读出"给定B，A和C条件独立"这样的结论。这在黑色箱的神经网络中是做不到的。

### 隐马尔可夫模型与语音识别

隐马尔可夫模型（Hidden Markov Model，HMM）是概率图模型中应用最成功的一种。HMM假设系统在一个有限的隐状态集合中转移，每次转移生成一个观测值。你看不到隐状态，只能通过观测值推断。

```
隐状态: S₁ → S₂ → S₃ → ...
观测值: O₁    O₂    O₃   ...
```

HMM有三个核心问题：
- 评估（给定模型，观测序列的概率？）→ 前向算法
- 解码（给定模型和观测，最可能的隐状态序列？）→ Viterbi算法
- 学习（给定观测，如何估计模型参数？）→ Baum-Welch算法（EM算法的变体）

1980s-1990s，HMM+GMM（高斯混合模型）成为语音识别的标准方案。GMM建模每个隐状态的观测分布，HMM建模状态之间的转移。这个组合在语音识别领域统治了近二十年。

### 贝叶斯方法的哲学优势与计算劣势

贝叶斯方法有一个优雅的哲学框架：**用概率表达不确定性**。先验P(θ)表示你在看到数据之前对参数的信念，似然P(D|θ)表示数据对参数的支持，后验P(θ|D)表示你在看到数据之后对参数的更新信念。

```
P(θ|D) ∝ P(D|θ) · P(θ)
后验   ∝ 似然  × 先验
```

但贝叶斯方法有一个严重的计算问题：**后验分布通常没有解析解**，需要用MCMC或变分推断等近似方法计算。这些方法在高维空间中极其缓慢，限制了贝叶斯方法的实际应用。

这个"理论优雅但计算困难"的困境，在深度学习时代被变分自编码器（VAE）部分解决——用神经网络近似后验分布。但那是后话了。

## 特征工程的时代

在统计学习的黄金年代，有一个贯穿所有方法的隐含假设：**特征是给定的**。

你用什么特征喂给SVM、随机森林、HMM，完全取决于你自己。SIFT（1999）用于图像特征提取——它通过在多个尺度上检测关键点，生成对旋转、缩放、光照变化鲁棒的特征描述符。HOG（2005）用于行人检测——它统计局部梯度方向直方图，捕捉物体的轮廓信息。MFCC用于语音——它提取频谱的包络特征，对应人耳对频率的感知方式。

这些特征工程的成功背后是一个深刻的矛盾：**特征决定了模型性能的上限，而模型只是逼近这个上限**。

如果你的SIFT特征不能捕捉遮挡、形变、视角变化，再好的SVM也无法弥补。如果你的MFCC特征丢失了语音的相位信息，再复杂的HMM也无法恢复。特征工程把人类对问题的理解编码成特征，但人类理解有盲区——我们可能不知道什么特征是关键的，或者知道了但无法高效提取。

这就是深度学习的根本动机：**让模型自己学特征**。不用人类告诉它"边缘很重要""梯度方向很有用"，让它从数据中自己发现什么特征对分类有帮助。从特征工程到特征学习的转变，是深度学习对机器学习最重要的贡献。

但要做到这一点，需要解决两个问题：一是如何高效训练深层网络（反向传播已经解决但梯度消失还没解决），二是如何获得足够大的数据集让深层网络有足够的信息学习。

这两个问题在2000s开始有了答案。

## 本章技术要点

1. **SVM的核心**：最大间隔分类+核技巧。最大间隔保证泛化性能（结构风险最小化），核技巧让线性分类器在非线性问题上也能工作。SVM是统计学习理论的巅峰，有严格的数学保证。

2. **集成方法**：多样性比个体强度更重要。Bagging（随机森林）降低方差，Boosting（AdaBoost）降低偏差。Dropout是集成思想在深度学习中的变体。

3. **概率图模型与HMM**：用概率表达不确定性，用图结构编码变量关系。HMM+GMM统治语音识别近二十年。贝叶斯方法理论优雅但计算困难。

4. **特征工程的核心矛盾**：特征决定上限，模型逼近上限。人类设计的特征有盲区，深度学习的目标是让模型自己学特征。

5. **统计学习时代的遗产**：SVM的核技巧思想（在高维空间中解决问题）影响了后来的词嵌入（Word2Vec把词语映射到高维向量空间）；集成方法的思想影响了Dropout和模型融合；概率图模型的思想影响了VAE和扩散模型。技术会过时，思想不会。
