# 第4章：神经网络复兴——反向传播的时代（1980s）

1986年，David Rumelhart、Geoffrey Hinton和Ronald Williams在Nature上发表了一篇论文，标题是《Learning representations by back-propagating errors》。这篇论文重新发现并推广了反向传播算法，用实验证明了多层神经网络可以被有效训练。

这篇论文的影响力远超Werbos1974年的原始工作。不是因为Rumelhart等人做了什么Werbos没做的事——算法的核心是相同的链式法则。而是因为他们在**正确的时机**，用**正确的实验**，在**正确的期刊**上，向**正确的受众**展示了结果。

时机：1980s中期，符号AI的瓶颈已经很明显，学界开始重新寻找替代方案。实验：他们在多个任务上展示了多层网络的实际效果，不只是理论推导。期刊：Nature是跨学科的顶级期刊，不只是AI圈的自留地。受众：不只是AI研究者，还包括认知科学家、神经科学家、物理学家——这些人对"学习"路线更开放。

## 反向传播算法：完整推演

让我们完整地推演一遍反向传播，因为这是理解整个深度学习的基础。如果你理解了这个算法，后续的CNN、Transformer、大模型训练都只是在这个基础上做架构创新和工程优化。

### 前向传播

考虑一个三层神经网络：

```
输入层 → 隐藏层 → 输出层
x       h        y
```

前向传播的计算过程：

```
h = σ(W₁ · x + b₁)    # 隐藏层：线性变换 + 激活函数
y = σ(W₂ · h + b₂)    # 输出层：线性变换 + 激活函数
```

其中σ是激活函数（如sigmoid σ(z)=1/(1+e⁻ᶻ)），W₁和W₂是权重矩阵，b₁和b₂是偏置。

### 计算损失

给定目标输出t，计算损失函数（如均方误差）：

```
L = ½Σ(yᵢ - tᵢ)²
```

### 反向传播

反向传播的目标：计算∂L/∂W₁和∂L/∂W₂——每个权重对损失的梯度。有了梯度，就可以用梯度下降更新权重：

```
W = W - η · ∂L/∂W    # η是学习率
```

**输出层的梯度**（直接计算）：

```
∂L/∂W₂ = (∂L/∂y) · (∂y/∂W₂)
         = (y - t) · σ'(W₂·h + b₂) · h
```

这里(y-t)是损失对输出的梯度，σ'是激活函数的导数，h是隐藏层的输出（作为W₂的"输入"）。

**隐藏层的梯度**（需要链式法则）：

```
∂L/∂W₁ = (∂L/∂y) · (∂y/∂h) · (∂h/∂W₁)
         = (y - t) · σ'(W₂·h + b₂) · W₂ · σ'(W₁·x + b₁) · x
```

注意这里的关键步骤：∂L/∂h不是直接计算的，而是通过∂L/∂y和∂y/∂h间接得到的。这就是"反向传播"——梯度从输出层反向传到隐藏层。

### 为什么叫"反向传播"

在前向传播中，信息从输入流向输出：x → h → y。

在反向传播中，梯度从输出流向输入：∂L/∂y → ∂L/∂h → ∂L/∂W₁。

两个方向相反。这就是名字的由来。

### 计算图的视角

更一般地，可以把神经网络看作一个**计算图**（Computational Graph）——每个节点是一个运算，每条边是数据的流动。

```
x ──→ [W₁·x+b₁] ──→ [σ] ──→ h ──→ [W₂·h+b₂] ──→ [σ] ──→ y ──→ [loss] ──→ L
```

反向传播就是在这个图上反向走，每一步乘上局部梯度。这个视角的好处是：**不管网络有多复杂（CNN、Transformer、任何架构），反向传播的原理都是一样的**——在计算图上反向传播梯度。

这也是为什么深度学习框架（PyTorch、TensorFlow）的核心功能是"自动微分"——你只需要定义前向传播（计算图），框架自动帮你算反向传播。你不需要手动推导梯度。

## 卷积的早期思想：Neocognitron（1980）

反向传播让多层网络可以训练了，但"多层全连接网络"有一个问题：**参数太多**。一个100×100的图像有10000个像素，如果隐藏层有1000个神经元，仅第一层的权重就有10000×1000=1000万个参数。这么多参数，训练起来极慢，而且容易过拟合。

1980年，日本研究者Kunihiko Fukushima提出了Neocognitron——一个受视觉皮层结构启发的神经网络。Neocognitron的关键创新是**层次化特征提取**：

```
输入图像 → S层（简单细胞：提取局部特征） → C层（复杂细胞：整合局部特征，容忍位置偏移）
→ S层 → C层 → ... → 最终识别
```

每一层S细胞只看输入的一个小区域（局部感受野），提取该区域内的简单特征（如边缘）。C细胞把多个S细胞的输出整合，允许特征在位置上有一定偏移——同一个边缘出现在图像的不同位置，C细胞都能识别。

这个设计直接对应了Hubel和Wiesel在1962年发现的视觉皮层结构：简单细胞检测局部边缘，复杂细胞整合简单细胞的输出，形成位置不变的特征表示。

Neocognitron没有使用反向传播训练（它用的是一种更复杂的无监督+有监督混合方法），而且架构也跟后来的CNN不完全相同。但它的核心思想——**局部感受野 + 层次化特征提取 + 位置不变性**——正是后来CNN的基础。

Yann LeCun在1989年把这些思想跟反向传播结合起来，创造了LeNet——第一个真正实用的卷积神经网络。但那是下一个时代的故事了。

## 神经网络的第二次热潮与再次冷却（1990s初）

反向传播的成功引发了神经网络的第二次热潮。1987-1992年间，大量论文发表，大量经费投入，大量公司成立。人们再次相信神经网络即将解决一切问题。

但这次热潮也很快冷却了。三个原因：

### 梯度消失问题

这是多层网络训练中最顽固的敌人。

考虑一个很深的网络，用sigmoid激活函数。sigmoid的导数σ'(z) = σ(z)(1-σ(z))，最大值只有0.25（在z=0时）。这意味着，每经过一层，梯度就被乘以一个不超过0.25的因子。

```
10层网络：梯度最多被乘以 0.25¹⁰ ≈ 0.0000001
20层网络：梯度最多被乘以 0.25²⁰ ≈ 0.0000000000001
```

梯度指数级衰减。到了靠近输入的层，梯度几乎为零——权重几乎不更新。这些层"学不动"。

这就是**梯度消失**（Vanishing Gradient）问题。它不是bug，而是sigmoid激活函数+深层网络的数学必然。Hinton在1986年的论文中已经隐含地提到了这个问题，但当时网络只有2-3层，问题不明显。当人们尝试训练更深的网络时，问题就暴露了。

梯度消失的对应问题是**梯度爆炸**（Exploding Gradient）——如果权重初始化不当，梯度可能在反向传播中指数级增长，导致数值溢出。但实践中，消失比爆炸更常见也更难解决。

### 过拟合

多层网络参数量大，但1980s-1990s的数据集很小。一个有几千个参数的网络，在几百个训练样本上，很容易"记住"训练数据而不是"学会"规律。在训练集上表现完美，在新数据上表现很差。

过拟合的直觉：想象你只有10道数学题的答案，你把这10道题的解法背下来了，考试时遇到新题就完全不会。模型也是这样——参数太多、数据太少，它就倾向于死记硬背。

### 算力瓶颈

1990s的CPU训练一个稍大的神经网络需要数周甚至数月。GPU还没有被用于神经网络训练（CUDA要到2007年才发布）。研究者要么等很久，要么只能用很小的网络——而小网络的能力有限。

这三个问题——梯度消失、过拟合、算力——形成了一个恶性循环：深层网络训练不动→只能用浅层网络→浅层网络能力有限→效果不好→经费削减→研究再次进入低谷。

## 过渡：从"让机器学"到"给机器好的特征"

神经网络再次冷却后，AI研究的主流转向了一个务实的中间路线：**不指望机器自己学特征，而是由人类设计好特征，让机器只学最后的分类决策**。

这就是特征工程（Feature Engineering）的时代。人类专家精心设计特征提取算法——SIFT（尺度不变特征变换，1999）用于图像、MFCC（梅尔频率倒谱系数）用于语音、TF-IDF用于文本——然后把这些手工特征喂给相对简单的分类器（SVM、随机森林）。

这个路线在1990s-2000s取得了大量实际成功。但它有一个根本性的局限：**特征决定了性能的上限，模型只是逼近这个上限**。如果你的SIFT特征不能捕捉旋转不变性，再好的SVM也无法弥补。

打破这个局限需要让机器自己学特征——这正是深度学习要做的事。但深度学习需要三个条件：算法（解决梯度消失）、算力（GPU）、数据（大规模数据集）。这三个条件要到2000s才逐步满足。

## 本章技术要点

1. **反向传播的完整流程**：前向传播计算输出→计算损失→反向传播计算梯度→梯度下降更新权重。核心是链式法则在计算图上的应用。不管网络架构如何（CNN、Transformer、任何架构），反向传播的原理都一样。

2. **计算图视角**：神经网络是一个计算图，前向传播是数据在图上正向流动，反向传播是梯度在图上反向流动。PyTorch/TensorFlow的自动微分就是基于这个原理。

3. **Neocognitron**：CNN的思想先驱。局部感受野+层次化特征提取+位置不变性，对应视觉皮层的简单细胞和复杂细胞。

4. **梯度消失**：sigmoid激活函数的导数最大值0.25，多层叠加导致梯度指数级衰减。这是深层网络训练的核心障碍，后来被ReLU（导数恒为1）和残差连接（梯度直通）解决。

5. **第二次热潮与冷却的循环**：反向传播成功→热潮→深层网络训练不动→冷却。这个"热潮-冷却"的循环在AI历史上重复了三次（1950s感知机、1980s反向传播、2020s大模型可能也会面临类似问题）。

6. **特征工程的过渡**：人类设计特征+机器学分类。特征决定上限，模型逼近上限。打破这个局限需要让机器自己学特征——深度学习的核心动机。
